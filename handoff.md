# Rclone Mega — handoff

Current version: 0.10.1.

Autofit measures column contents and resizes the whole window to the table;
manual column resizing preserves the current window width. Verification:
204 tests, Ruff and OSV dependency checks. Packaging validates native binary
origins, the complete Qt MSVC runtime and an isolated frozen GUI/runtime smoke.

Use a project .venv and follow DEVELOPER.md for development and builds.
Settings, credentials and run reports are created locally and excluded from
the public installer. The public repository contains a current source snapshot.
