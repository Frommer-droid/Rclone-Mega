# Rclone Mega icon

Created on 2026-10-15 using the built-in ImageGen tool.

Conceptual reference: [official Rclone website](https://rclone.org/) and its
[logo](https://rclone.org/img/logo_on_light__horizontal_color.svg).
The official artwork is research material only and is not included in the
application assets. The new mark uses two opposing arrows instead of the
official three interlocking loops. Different geometry and composition reduce
visual similarity; this is not a legal clearance or guarantee.

`logo.png` is the transparent master and README preview. `logo.ico` contains
16, 20, 24, 32, 40, 48, 64, 96, 128 and 256 pixel frames for the existing
application, tray and build references. Existing executables require rebuilding
to update their embedded icon.

## Generation prompt

Use case: logo-brand. Create one original Windows application icon for Rclone Mega, a cloud file synchronization utility. The official Rclone mark was researched: three interlocking blue loops in a triangular arrangement. Use only the broad idea of connection and transfer as conceptual inspiration, NOT its three loops, triangular silhouette or exact geometry. Invent a distinctly different simple mark: TWO bold, solid, smoothly bent opposing arrows, one rich cobalt blue and one bright cyan, forming a compact near-square horizontal transfer loop with a clean open center. Only two large shapes, no other symbols. Flat vector-like graphic, crisp edges, optical balance, very thick forms, minimal detail, instantly legible at 16px. The symbol fills about 90% of the square canvas with narrow even margins. True transparent background. No enclosing tile or frame, no cloud, no extra circles, no interlaced outlines, no thin lines, no letters, no words, no shadows, no 3D, no watermark. One single finished icon, no presentation sheet.
