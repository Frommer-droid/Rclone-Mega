# Интерфейс Rclone Mega

Обновлён 15 октября 2026 года. Нативный Windows-интерфейс на PySide6,
каноническая тема владельца One Dark, шрифт Tahoma, шаг отступов 8 DIP.

Таблица заполняет всю рабочую ширину окна. «Автоподбор» измеряет содержимое
столбцов и изменяет ширину самого окна под таблицу с учётом отступов и рамок.
Высота сохраняется, размер ограничен рабочей областью экрана; развёрнутое окно
возвращается в обычный режим. Перетаскивание границы перераспределяет
место за счёт соседних столбцов. Пропорции сохраняются между запусками.

«Настройки → Масштаб интерфейса» содержит привычный выбор 50–150%.
Он меняет размер текста, отступов, значков, кнопок, таблицы и диалогов поверх
автоматической адаптации к экрану. Выбор сохраняется; смена монитора не
вызывает принудительного изменения размера окна.

Основной экран показывает задачи, аккаунт и состояние. Синий акцент выделяет
главное действие зеркалирования; служебные действия нейтральные, опасные —
приглушённые красные. Статусы имеют текст и дополнительный цвет. Настройки
движка и автозапуска раскрываются кнопкой «Настройки», журнал — в шапке.
Редактор разделяет папки, расписание, безопасность и фильтры; скрытые вкладки
сохраняют все поля при редактировании названия или пути.

Использованы установленные навыки `one-dark-theme`, `python-pyside6-desktop-app`,
`ui-ux-pro-max`, `better-layout`, `better-typography`, `better-ui`,
`better-accessibility`, а также навыки рабочего процесса и Context7.
Новые навыки из маркетплейсов не устанавливались. Общая выдача UI Pro Max
предлагала шаблон лендинга и другую палитру; они не применялись. Узкий поиск
по таблицам подтвердил целесообразность компактных повторяющихся действий.

Референсы изучались для принципов взаимодействия, без копирования оформления:

- [FreeFileSync: основной рабочий процесс](https://freefilesync.org/manual.php?topic=freefilesync) —
  сначала сравнение, затем синхронизация.
- [Microsoft: раскрытие дополнительных настроек](https://learn.microsoft.com/en-us/windows/win32/uxguide/ctrl-progressive-disclosure-controls) —
  сохранять основные команды видимыми, дополнительные показывать по запросу.
- [Qt: стилизация виджетов](https://doc.qt.io/qtforpython-6/tutorials/basictutorial/widgetstyling.html) —
  единая тема и состояния элементов; API проверены через Context7.
