# История изменений (Release Notes)

## Версия 0.8.0 (2026-10-09)

*Сортировка таблицы задач и удобный запуск исходников из избранного разработчика.*

### ✨ Возможности

- Нажатие на заголовки «Имя», «Аккаунт», «Запуск», «Режим», «След. попытка» и «Статус» сортирует строки; повторное нажатие меняет направление.
- Стрелка показывает направление сортировки. Даты сравниваются хронологически, текст — без учёта регистра.
- Сортировка сохраняется при обновлении таблицы и фильтрации аккаунтов в текущем сеансе. Выбор, галочки и действия остаются привязаны к нужной задаче.

### 🛠 Улучшения

- Исходники запускаются через `Rclone Mega-run.cmd` из проектной `.venv`.
- Сборочные кеши и рабочие каталоги сохраняются; временные файлы сборки и установщика вынесены в каталог разработки.

### 📚 Документация

- Обновлены описание сортировки, команды сборки и скриншот общего списка задач.

## Версия 0.7.0 (2026-10-06)

*Общий обзор аккаунтов, единое подтверждение массового зеркалирования и ограничение памяти при больших проверках.*

### ✨ Возможности

- Общий список задач всех аккаунтов с отдельной колонкой аккаунта и фильтром подключения.
- «Зеркалировать всё» заново проверяет включённые задачи, собирает одно подтверждение и последовательно выполняет выбранные задачи по аккаунтам.

### 🐛 Исправления

- Журнал сохраняет последние 2000 блоков и ограничивает длину сообщений, включая скрытый журнал.
- Результаты проверки сохраняют до 100 примеров на задачу при полном подсчёте изменений и удалений.
- Старые настройки с большими списками деталей нормализуются без изменения параметров задач.
- Runner освобождает прошлый вывод; переполнение диагностического вывода отмечается как неполный результат и не допускает подтверждения зеркалирования.

### 📚 Документация

- Описаны общий обзор аккаунтов, массовое подтверждение и ограничения журналов и деталей проверки.

## Версия 0.6.0 (2026-10-04)

*Управление удалением в MEGA, автоматические исключения кешей и стабильное положение окон.*

### ✨ Возможности

- Для каждой задачи добавлен переключатель безвозвратного удаления в MEGA.
  По умолчанию он выключен; резервная папка `backup-dir` имеет приоритет.
- Кеши Python и распространённые временные файлы исключаются автоматически,
  в том числе при пользовательских include-фильтрах. Уже исключённые файлы
  в облаке сохраняются; автоматическая очистка облачных кешей не выполняется.

### 🐛 Исправления

- Главное окно восстанавливает Qt geometry без смещения при повторном запуске.
  Координаты диалогов сохраняются с учётом рамки окна.
- Обновление portable сохраняет настройки задач вместе с `rclone.conf`.
- Установщик выбирает `D:\Apps` на целевой машине либо `C:\Apps`, если диска D нет;
  интерфейс установки всегда русский.

### 🛡️ Сборка и поставка

- В корне frozen runtime используется полный согласованный набор MSVC DLL от Qt.
- Публичный установщик не содержит личных настроек и подключений.
- Проверены тесты исходников, Ruff, происхождение DLL и frozen runtime.

## Версия 0.5.2 (2026-09-16)

*Patch-релиз с запоминанием положения окон и усиленной безопасностью Windows-сборки.*

### 🛠 Улучшения

- Главное окно, диалог подтверждения зеркалирования и диалог задачи сохраняют
  размер и положение между запусками. Восстановленные координаты ограничиваются
  доступной областью текущего экрана.

### 🛡️ Надёжность сборки

- PyInstaller перед анализом зависимостей использует минимальный доверенный
  `PATH` и прекращает сборку, если обнаруживает бинарный файл из постороннего
  каталога.
- MSVC runtime в onedir-сборке дополнительно проверяется: DLL должны поступать
  из runtime текущего PySide6, а не из базового Python или внешнего toolchain.

### 📦 Публичная поставка

- Добавлена лицензия MIT для собственного кода, а уведомление о лицензии
  встроенного rclone сохранено отдельно.
- README теперь доступен на русском и английском; документация ссылается на
  страницу последнего релиза вместо конкретной версии installer.
- Папка portable-сборки настраивается локальной переменной
  `RCLONE_MEGA_PORTABLE_DIR`; личный путь разработчика не публикуется.

### ✅ Проверки

- `ruff check .`
- `pytest tests`
- PyInstaller onedir build, проверка `COLLECT-00.toc` и frozen smoke-test

## Версия 0.5.1 (2026-07-18)

*Patch-релиз с адаптивным окном подтверждения планового зеркалирования.*

### 🐛 Исправления ошибок

- Длинный список задач и найденных изменений в окне подтверждения теперь
  прокручивается, а кнопки зеркалирования, отсрочки и отключения интервала
  остаются постоянно доступными.
- Высота окна подтверждения ограничена 85% рабочей области текущего монитора,
  поэтому диалог не выходит за границы экрана.
- Обновление portable-папки теперь сохраняет существующий `rclone.conf`, поэтому
  настроенные remote не теряются при установке новой версии.
- Неудачный dry-run больше не подписывается как успешная проверка без изменений.

### 📦 Улучшения релиза

- В установщик добавлена отмеченная по умолчанию галочка запуска приложения
  после завершения обычной интерактивной установки; в тихом режиме приложение
  не запускается.

### ✅ Проверки

- `ruff check app tests`
- `pytest tests`

## Версия 0.5.0 (2026-05-01)

*Релиз с поддержкой нескольких MEGA remote в одном `rclone.conf`, импортом учетных данных из INI-файла и проверкой квоты выбранного облака.*

### ✨ Новые возможности

- Блок подключения теперь показывает список настроенных remote и фильтрует
  таблицу задач по выбранному подключению.
- Добавлен импорт нескольких MEGA remote из INI-файла: секции могут быть
  именами remote или email-адресами, а пароль/2FA читаются только на момент
  настройки и не сохраняются в `settings.json`.
- `rclone.conf` может содержать несколько MEGA-аккаунтов; приложение больше не
  привязано к единственному имени `mega:`.
- Для выбранного remote добавлена проверка доступности и отображение квоты через
  `rclone about <remote>: --json`.
- Диалог задачи выбирает remote из списка настроенных подключений и проверяет,
  что основной путь и `backup-dir` используют существующий remote.

### 🐛 Исправления ошибок

- Сохранение настроек теперь хранит список известных remote и выбранный remote
  отдельно от задач, без попытки угадывать подключения из runtime-путей.
- Массовые действия в таблице работают только с задачами выбранного remote.
- Диагностический вывод quota JSON не попадает в пользовательский журнал, но
  остается доступен обработчику результата.

### 📚 Документация

- README описывает импорт INI-файла, несколько remote, проверку выбранного
  подключения и новый формат примеров задач.
- DEVELOPER уточняет модель хранения remote, правила импорта учетных данных,
  фильтрацию задач и проверку квоты.

### ✅ Проверки

- `ruff check .`
- `pytest tests`

## Версия 0.4.0 (2026-04-29)

*Релиз с ordered-фильтрами rclone для разрешённых подпапок, исправленным tray-меню и подготовкой private disaster-recovery backup контура.*

### ✨ Новые возможности

- В настройках задачи добавлено поле `Фильтры rclone` для ordered filter rules.
- Для сценария "зеркалировать только выбранные подпапки" достаточно указать include-правила вида `+ /Нужная/**`; если все правила являются include-правилами, приложение автоматически добавляет финальное `- /**`.
- Старое поле `Exclude` сохранено для простых исключений и при включённых `Фильтры rclone` преобразуется в ordered `- pattern` правила перед пользовательскими фильтрами.
- В runtime-настройках подготовлены задачи `DR-*` для private backup контура восстановления после сбоя Windows/диска: Codex state, agents skills, SSH, PowerShell profiles, `.gitconfig`, VS Code, Windows Terminal, runtime Rclone-Mega и локальное состояние рабочих проектов.

### 🐛 Исправления ошибок

- Пункт `Выход` в контекстном меню иконки трея теперь завершает приложение через явный tray-exit путь.
- Пункт `Свернуть в трей` больше не показывается, когда окно уже скрыто в трее.
- Подсказка в поле фильтров теперь показывает пути относительно выбранной локальной папки задачи, без лишнего уровня `Папка`.

### 📚 Документация и восстановление

- README и DEVELOPER описывают новый режим `Фильтры rclone`, автоматическое исключение всего остального и поведение tray-меню.
- `.gitignore` исключает runtime backup-файлы вида `*.bak-*`.
- Глобальный recovery-навык дополнен `private-backup-manifest.md` с перечнем private backup путей и порядком восстановления.

### ✅ Проверки

- `ruff check app tests`
- `pytest tests`

## Версия 0.3.1 (2026-04-28)

*Patch-релиз с исправлением ложных dry-run изменений и артефактов кнопок в таблице задач.*

### 🐛 Исправления ошибок

- GUI-команды rclone больше не используют `-P/--progress` вместе с `--combined -`, чтобы progress-строки вида `* file: checking` не принимались за реальные изменения.
- Итоговая JSON-статистика rclone теперь является финальным фильтром dry-run: если `transfers`, `deletes`, `deletedDirs`, `renames` и server-side операции равны нулю, задача считается `Без изменений`.
- Combined-строки `= path`, означающие совпавшие файлы, больше не выводятся в журнал и не засоряют проверку.
- Колонка `Действия` получила фиксированную ширину, а кнопки строки фиксированные размеры, чтобы они не всплывали поверх соседних ячеек.

### ✅ Проверки

- `ruff check .`
- `pytest tests`
- прямой dry-run первой задачи: `There was nothing to transfer`, `transfers: 0`, `deletes: 0`

## Версия 0.3.0 (2026-04-28)

*Релиз с привязкой плановой проверки ко времени суток, более понятным dry-run и компактным управлением журналом.*

### ✨ Новые возможности

- В настройках задачи добавлена опция `Привязать к времени`: плановая проверка может запускаться около заданного времени суток при сохранении прежнего интервала.
- В таблицу задач добавлена колонка `След. попытка`, которая показывает ближайшее рассчитанное время проверки, ручной режим, паузу или ожидание первой проверки.
- Ручные кнопки `Проверить` и `Проверить все` теперь используют тот же сценарий подтверждения, что и автоматическая интервальная проверка.
- Заголовок колонки активности стал массовым переключателем: один клик включает все задачи, повторный клик отключает все.
- Журнал скрыт по умолчанию и раскрывается кнопкой `Показать журнал` в верхнем блоке MEGA без уменьшения текущей высоты блока задач.

### 🐛 Исправления ошибок

- Dry-run теперь запрашивает `rclone --combined -` и показывает, какие файлы отличаются, какие есть только локально и какие будут удалены из облака при зеркалировании.
- Статус отложенной синхронизации сокращен до `Отложено`, чтобы строка таблицы не растягивалась.
- Колонки таблицы задач уплотнены: длинные заголовки больше не диктуют чрезмерную ширину ячеек.
- `Ctrl+C`/`KeyboardInterrupt` при запуске из консоли корректно закрывает главное окно и возвращает код `130`.

### ✅ Проверки

- `ruff check .`
- `pytest tests`
- `vendor\rclone\rclone.exe version`

## Версия 0.2.0 (2026-04-28)

*Релиз с встроенным rclone, настройкой MEGA из приложения и обновленным release pipeline.*

### ✨ Новые возможности

- В приложение добавлен встроенный `vendor\rclone\rclone.exe`; отдельная установка rclone больше не нужна для обычного сценария.
- Все команды rclone теперь используют локальный `rclone.conf` рядом с приложением через `--config`.
- Добавлен диалог `Подключить MEGA`: приложение создает remote `mega:` через rclone, передавая пароль в `rclone obscure` через stdin.
- Основной экран рационализирован: пользователь видит действия MEGA, а выбор другого `rclone.exe`, версия и путь к конфигу спрятаны в `Дополнительно`.
- Старые настройки с внешним `rclone.exe` больше не переопределяют встроенный rclone без явного выбора внешнего файла.

### 🐛 Исправления ошибок

- Installer и staging очищают runtime `rclone.conf`, чтобы конфиг MEGA не попадал в установщик и публичный релиз.
- PyInstaller onedir включает `_internal\vendor\rclone\rclone.exe`, а post-build проверяет его наличие.
- `.gitignore` исключает локальный `rclone.conf`, распакованную папку rclone и runtime config внутри `vendor`.
- Добавлены тесты настройки MEGA, локального `--config`, миграции старого `settings.json` и скрытого блока rclone-диагностики.

### ✅ Проверки

- `ruff check .`
- `pytest tests`
- `vendor\rclone\rclone.exe version`

- Улучшен подсчет изменений в dry-run по выводу `rclone`.
